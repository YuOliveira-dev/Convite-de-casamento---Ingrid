# Wedding Invitation

## Objetivo

Criar um convite digital elegante, rápido e intuitivo.

O foco principal é proporcionar uma excelente experiência para convidados em dispositivos móveis.

Todo o projeto deve priorizar:

- Performance
- Simplicidade
- Elegância
- Fácil manutenção
- Escalabilidade

---

## Público

Convidados do casamento.

Grande parte acessará pelo WhatsApp.

---

## Filosofia

Less is More.

Poucos cliques.

Pouco texto.

Layout limpo.

Experiência agradável.

---

## Navegação

One Page.

Todo conteúdo deverá estar disponível através do scroll.

Nenhum menu complexo.

Nenhuma página interna.

A única exceção será:

- Lista de presentes

O Web App recebe as confirmações via GET com `action=Create` e grava os parâmetros `nome`, `telefone` e `mensagem` nas três colunas da planilha.

As ações disponíveis no Web App são `Read`, `Create`, `Update` e `Delete`. Nesta fase, o convite utiliza `Create`.
