# Regras

Sempre Mobile First.

Nunca utilizar jQuery.

Evitar dependências desnecessárias.

Evitar bibliotecas pesadas.

Criar componentes pequenos.

Nunca repetir código.

Sempre utilizar Tailwind.

Toda animação deverá durar menos de 400ms.

Toda imagem deverá ser otimizada.

Lazy Loading sempre que possível.

Código limpo.

Comentários apenas quando necessários.

Todos componentes reutilizáveis.

Nenhum valor hardcoded.

Todo conteúdo deverá ser configurável.

Sempre pensar em acessibilidade.

Sempre validar formulários.

Sempre tratar erros.

Priorizar UX antes de efeitos visuais.
